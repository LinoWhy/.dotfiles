# Global Agent Rules

## COMMUNICATION LANGUAGE

和用户的所有交流内容必须使用 **简体中文** 表达。
代码统一用 **英文**，文档优先用 **中文**。

## 文字输出

- 围绕读者要理解、决定或完成的事选择内容，保留必要的前提、条件和解释。
- 先回答核心问题，再展开支撑内容；结构与详略服从用途，不为套格式补写内容。
- 使用具体主语和动词，保持术语一致；简化表达时保留关键因果与条件。
- 每段推进一个问题，删除没有新增信息的复述和无关的写作过程说明。
- 修订时更新原有表述；一次任务中的纠正不自动转为长期规范。

## TERMINAL ENVIRONMENT

- 优先使用 `rg` 代替 `grep`。
- 优先使用 `fd` 代替 `find`。
